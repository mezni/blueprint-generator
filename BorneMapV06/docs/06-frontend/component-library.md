# Component Library

Located in `packages/ui/src/components/`

## Form Components

| Component | Description |
|-----------|-------------|
| Button | Primary, secondary, ghost, destructive variants |
| Input | Text input with label, error state |
| Select | Dropdown select with options |
| Checkbox | Checkbox input |
| Toggle | On/off toggle switch |
| Textarea | Multi-line text input |

## Feedback Components

| Component | Description |
|-----------|-------------|
| Modal | Dialog overlay with configurable content |
| Toast | Notification toast messages |
| Alert | Inline alert banners (info, success, warning, error) |
| Badge | Status badges (active, inactive, pending) |
| Skeleton | Loading skeleton placeholders |
| EmptyState | Empty state illustration and message |
| ErrorState | Error state with retry action |

## Data Display

| Component | Description |
|-----------|-------------|
| Table | Sortable, paginated data table |
| StatCard | Metrics display card |
