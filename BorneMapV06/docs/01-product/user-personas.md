# User Personas

## Public Driver

Anonymous user discovering charging stations.

**Capabilities:** browse stations, search/filter, view station details, view
reviews and ratings.

**Restrictions:** cannot authenticate, create favorites, or submit reviews.

## Registered Driver

Authenticated user with a personal profile.

**Capabilities:** all public capabilities, plus manage favorites, manage own
reviews, manage profile.

## Partner

Authenticated business user managing charging infrastructure.

**Capabilities:** manage own stations only, manage own chargers only, update
manual availability.

**Rule:** Partners are strictly scoped to their own organization. No cross-
organization access.

## Admin

Global system administrator.

**Capabilities:** full platform access, manage users and partners, manage
stations and chargers, moderate content.
