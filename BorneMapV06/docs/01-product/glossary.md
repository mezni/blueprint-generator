# Glossary

| Term | Definition |
|------|------------|
| Station | A physical location with one or more EV chargers |
| Charger | An individual charging unit at a station |
| Driver | An EV driver using the platform to find stations |
| Partner | A business entity that owns/manages stations |
| Admin | Platform administrator with full system access |
| GIS | Geographic Information System — spatial data layer |
| OCPP | Open Charge Point Protocol (out of scope for MVP) |
| Keycloak | Identity provider for authentication |
| Traefik | Reverse proxy / edge router for public access |
