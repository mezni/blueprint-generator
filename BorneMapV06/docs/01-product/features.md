# Core Features

## MVP Features

### Driver Features
- Station discovery
- Map-based browsing
- Nearby search
- Station details
- Search & filtering
- Public ratings and reviews

### Registered Driver Features
- Favorites
- Create/update/delete own reviews
- Profile management

### Partner Features
- Manage owned stations
- Manage chargers
- Update manual availability

### Admin Features
- Manage users
- Manage partners
- Manage stations and chargers
- Moderate reviews

## Out of Scope (MVP)

- OCPP integration
- Charging sessions
- Payments
- Billing
- Pricing
- Routing / navigation
